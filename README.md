# GitHub Beginner's Guide
How Can Beginners Get Started with GitHub?
First, you need to understand two concepts and the difference between them: Git is a software tool used to track changes in the state of files over time. GitHub is a website for uploading copies of Git repositories, offering a variety of convenient features.
You should focus on Git's history feature.
Here are a few important concepts you need to understand.
Such as: commit, branch, merge, tag, pull request, issue, WiKi, clone, fork.
Your most important task now is to familiarize yourself with the different parts of the GitHub website. Take a look at the various buttons on the page and try clicking on them—it’s like strolling through an unfamiliar city that will become your happy new home, where you might end up living for decades. GitHub is a vast kingdom, and its people are very friendly. If you have any other questions, feel free to ask anyone here—chances are, you’ll get an answer.
